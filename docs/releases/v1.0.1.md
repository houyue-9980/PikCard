# 拾卡 PikCard 1.0.1

下载 `PikCard-1.0.1.dmg`，拖进“应用程序”替换旧版即可。卡片、进度和设置完全兼容。

## 安全

- **卡片里的脚本不再运行**：Anki 卡片本身是网页，导入来路不明的卡组时，里面可能藏着会自己运行的代码。现在卡片只运行拾卡自己的显示脚本，卡片不能联网发送数据、不能跳到别的网页、不能嵌入网页。网上的图片和声音照常显示，卡片里的链接点了还是用浏览器打开
- **导入 .apkg 更安全**：解压前先检查压缩包里的文件路径，发现想写到别处的路径就停止导入；包里指向电脑上其他文件的“快捷方式”一律不读

## 安装

下载下面的 **PikCard-1.0.1.dmg**，打开后把 PikCard 拖进“应用程序”（会替换旧版本，卡片和设置都保留）。第一次打开请**右键点击 PikCard → 打开**。需要 macOS 15 或更新版本。

# PikCard 1.0.1

Download `PikCard-1.0.1.dmg` and drag it into Applications to replace the old version. Cards, progress and settings are fully compatible.

## Security

- **Scripts inside cards no longer run**: Anki cards are web pages, so a deck from an unknown source could hide code that runs on its own. Now only PikCard's own display script runs; cards can't send data over the network, navigate to other pages or embed web pages. Images and audio from the web still show, and links in cards still open in your browser
- **Safer .apkg import**: archive paths are checked before extracting, and import stops if any file would land outside the import folder; links inside the package that point to other files on your Mac are never read

## Install

Download **PikCard-1.0.1.dmg** below, open it and drag PikCard into Applications (replaces the old version; cards and settings are kept). The first time, **right-click PikCard → Open**. Requires macOS 15 or later.
