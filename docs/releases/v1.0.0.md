# 拾卡 PikCard 1.0.0

拾系列的第二款软件，第一版。

- 卡组书架：每个卡组一个文件夹，卡片存在普通的 `cards.md`，进度存在 `progress.json`
- 复习：对 / 错 两键，或 忘了 / 难 / 记得 / 简单 四键；FSRS 安排复习时间
- 错题：答错自动进，连续答对 3 次移出；可以单独练
- 分类：给卡片加标签，按分类复习或练习
- 导入导出：Anki `.apkg`（新旧格式）、`.csv`、`.tsv`
- 公式、图片、声音；浅色 / 深色 / 护眼；中文 / English

# PikCard 1.0.0

The first release of the second app in the 拾 series: deck folders with plain Markdown cards, Right / Wrong or four-level answers scheduled by FSRS, a Mistakes list, tags, and import / export for Anki `.apkg`, `.csv` and `.tsv`.
