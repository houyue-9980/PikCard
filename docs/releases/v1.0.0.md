# 拾卡 PikCard 1.0.0

拾系列的第二款软件：超轻量的 Mac 原生背诵卡，第一版。

## 功能

- **数据在你手里**：每个卡组是一个普通文件夹，卡片存在 `cards.md`（普通 Markdown），复习进度存在 `progress.json`，图片声音放在 `media/`。放进 iCloud 云盘或 OneDrive 就能同步
- **复习**：空格翻面看答案；默认只选“对 / 错”（← →），设置里可以换成“忘了 / 难 / 记得 / 简单”四档（1–4）；用 FSRS 算法安排下次复习时间；⌘Z 撤销，E 编辑当前这张
- **错题**：答错自动进错题，可以单独练，连续答对 3 次自动移出
- **分类**：给卡片加标签，按分类复习或练习
- **导入导出**：Anki `.apkg`（新旧格式，含图片和声音）、`.csv`、`.tsv`；文件拖进窗口或程序坞图标就能导入
- **书架**：拖动卡组换位置；图标可以选任意表情、任意底色
- **卡片内容**：Markdown、公式（KaTeX）、图片、声音
- **外观**：浅色 / 深色 / 护眼，中文 / English

## 安装

下载下面的 **PikCard-1.0.0.dmg**，打开后把 PikCard 拖进“应用程序”。第一次打开请**右键点击 PikCard → 打开**。需要 macOS 15 或更新版本，Apple 芯片的 Mac。

# PikCard 1.0.0

The second app in the 拾 series: a lightweight native Mac flashcard app. First release.

## Features

- **Your data stays yours**: each deck is a plain folder; cards live in `cards.md` (plain Markdown), progress in `progress.json`, images and audio in `media/`. Put it in iCloud Drive or OneDrive to sync
- **Review**: Space flips the card; answer Right / Wrong (← →) by default, or switch to Again / Hard / Good / Easy (1–4) in Settings; FSRS schedules the next review; ⌘Z undoes, E edits the current card
- **Mistakes**: wrong answers go into Mistakes for focused practice and leave after 3 right answers in a row
- **Tags**: tag cards and review or practice one tag at a time
- **Import & export**: Anki `.apkg` (old and new formats, with images and audio), `.csv`, `.tsv`; drag files onto a window or the Dock icon to import
- **Shelf**: drag decks to reorder; pick any emoji and any color for the icon
- **Card content**: Markdown, math (KaTeX), images, audio
- **Appearance**: Light / Dark / Sepia, English / 中文

## Install

Download **PikCard-1.0.0.dmg** below, open it and drag PikCard into Applications. The first time, **right-click PikCard → Open**. Requires macOS 15 or later on a Mac with Apple silicon.
